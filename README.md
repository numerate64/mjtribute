# Michael Jackson August Tribute

An August tribute presentation honoring Michael Jackson's birth month.

## Contents

- `Michael-Jackson-August-Tribute.pptx` - 31-slide editable PowerPoint deck, one slide for each day in August.
- `michael-jackson-august-beautifulai-prompt.md` - prompt used to generate the Beautiful.ai version.
- `michael-jackson-august-beautifulai-response-2026-08-02.json` - Beautiful.ai API response with the player URL.
- `generate-deck.js` - local PPTX generator.
- `ARTWORK-SOURCES.md` - local artwork source notes.
- `assets/` - album artwork assets used by the PPTX generator.

## Notes

## GitHub Pages App

The static site opens to the current day of the month and displays that day's August tribute song. Calendar buttons let visitors preview any other August date. A page refresh recalculates the current day and returns to today's song.
